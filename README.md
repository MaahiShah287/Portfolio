> Computer Engineering student passionate about turning data into meaningful insights and building practical analytics solutions.

## 🛠️ Tech Stack & Skills
- **Frontend / UI:** React, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Data & Analytics:** Python, SQL, Power BI, Excel, Machine Learning

## 💻 Getting Started Locally

### Prerequisites
Make sure you have Node.js installed (v18 or newer recommended).

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the portfolio.

### Production Build
```bash
npm run build
```
The production bundle will be generated in the `dist` folder.
